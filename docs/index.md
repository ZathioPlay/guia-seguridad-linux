# Guía Técnica de Seguridad en Servidores Linux

Bienvenido a la documentación oficial del proyecto técnico elaborado por **Daniel**.

## Objetivo del proyecto

Este portal recoge los procedimientos esenciales para auditar, proteger y mantener un servidor **GNU/Linux** en un entorno de producción profesional, minimizando su superficie de ataque frente a accesos no autorizados.

!!! info "Sobre esta documentación"
    Este sitio ha sido construido con **MkDocs** y el tema **Material for MkDocs**, aplicando control de versiones mediante Git y despliegue continuo en GitHub Pages.

## Estructura de contenidos

* **Introducción:** Contexto de la ciberseguridad en sistemas Linux y arquitectura de red.
* **Instalación y Requisitos:** Preparación del entorno base, actualizaciones y herramientas necesarias.
* **Uso y Funcionamiento:** Configuración de cortafuegos (UFW), endurecimiento de SSH y prevención de intrusiones.
* **Conclusiones:** Valoración técnica del proyecto y futuras líneas de mejora.
